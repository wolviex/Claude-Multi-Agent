# Page Title Alert

## Purpose

Shows the current page title in an alert box.

## Requirements

- Runs on any page.
- Needs no network access.

## Copyable URL

```text
javascript:(()=>{const t=document.title;alert(t)})()
```

## Readable code

```js
// Show the current page title in an alert box.
(() => {
  const t = document.title;
  alert(t);
})();
```
